# 🎯 Plinko CMD (Batch Edition)

A Windows Command Prompt-based Plinko game built using Batch scripting.  
Drop the ball, earn money, survive with hearts, and test your luck against pure RNG chaos.

---

## 🎮 Game Overview

Plinko CMD is a simple terminal game where a ball drops through a randomized Plinko board.  
Your goal is to earn as much money as possible while surviving as long as you can.

But be careful… there’s an **[X] slot** that takes away your hearts.

---

## 🧠 How to Play

- Watch the ball fall through the Plinko board
- Earn money based on the slot you land in
- Avoid the **[X] slot** (loses 1 heart)
- Lose all hearts = Game Over

---

## ❤️ Hearts System

- You start with **3 hearts**
- Each [X] hit removes 1 heart
- Survive as long as possible
- Try to maximize your earnings before losing all lives

---

## 🎮 Controls

- Use number inputs to navigate menus
- Press **Enter** to continue prompts
- Follow on-screen instructions during gameplay

---

## 🚀 Features

- 🎲 Randomized Plinko physics (Batch RNG logic)
- ❤️ Heart-based survival mode
- 💰 Money earning system
- ⚠️ Risk slot ([X]) mechanic
- 🪟 Lightweight Windows CMD gameplay (no external dependencies)
